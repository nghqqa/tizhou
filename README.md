# 题舟

> 题海行舟，终将上岸。

[![License: MIT](https://img.shields.io/badge/License-MIT-2f855a.svg)](LICENSE)

一个开源、本地优先、支持自定义题库与可选 AI 的考试学习工作台。基于 MIT 开源技术栈构建，数据完全由自己掌握。

## 它能做什么

| 模块             | 功能                                                                                          |
| ---------------- | --------------------------------------------------------------------------------------------- |
| **题库直导**     | 题本+解析/答案册 PDF 扫描件一键导入：本地 OCR 识别 → 自动切题配对 → 与现有题库去重 → 抽查入库 |
| **真题原卷模考** | 161 套历年真题按原题号整卷组卷、限时 120 分钟                                                 |
| **行测训练**     | 顺序、随机、自适应训练，即时或汇总解析，断点续练                                              |
| **错题复习**     | 错因记录、相似题、分级间隔复习和 AI 深度讲解                                                  |
| **申论作答**     | 给定材料+题干+草稿自动保存+AI 评估                                                            |
| **跨机迁移**     | 一键导出/导入迁移包，学习数据与题库完整搬迁                                                   |
| **AI 助教**      | 可选接入 DeepSeek、通义千问、Ollama 等模型，或不装模型纯离线使用                              |

## 下载安装

在 [GitHub Releases](https://github.com/nghqqa/tizhou/releases/latest) 下载 Windows x64 安装包，并使用同页的 `SHA256SUMS.txt` 校验文件完整性。

安装后可以直接使用内置示例知识库体验训练、模考、申论和报告功能。模型与自定义资料均为可选配置。

题库数据不随仓库分发，导入方式见[《题库导入指南》](docs/question-bank-import.md)。

## 快速上手（3 分钟）

1. **装好应用** → 环境与数据 → 安装转换引擎（首次使用，含 OCR 组件约 200 MB）
2. **导题库** → 知识构建 → 选文件夹 → 产物类型「直导题库」→ 开始 → 抽查后发布
3. **开刷** → 行测训练 / 模拟考试 / 申论作答

## 项目结构

```
src/
├── main/          Electron 主进程：数据库、题库解析、OCR、迁移
├── renderer/      React 界面：训练、模考、知识中心、设置
├── shared/        类型契约与 Prompt 协议
└── preload/       IPC 桥
tools/             直导脚本与 OCR 工作进程
tests/             Vitest 集成测试
```

## 开发

```bash
npm install
npm run dev        # 开发模式
npm test           # 运行测试
npm run package    # 打包 Windows 安装包
```
