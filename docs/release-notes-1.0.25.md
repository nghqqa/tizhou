# 题舟 v1.0.25

全面提升高分大屏与长时间刷题的阅读舒适度，并解除大型共享题库的 5 万文件索引上限。

## 新特性与改进

- **全站默认字号升级与题干层级修复**：修复 Markdown 渲染覆盖题干字号的问题，题干升至 17px 高对比排布，全站字号整体上调一档并消除 10px 极小标签
- **持久化界面缩放与快捷键**：在「应用设置」新增 90%–150% 界面缩放档位，并支持随时按 `Ctrl +` / `Ctrl -` / `Ctrl 0` 等比缩放与重置，重启后自动恢复
- **申论页可选「公文体」排版**：申论作答工具条新增「公文体」开关，一键切换仿宋正文、黑体/楷体标题与首行缩进，贴近党政机关公文阅读观感
- **支持超 5 万题大型题库**：移除知识库 Markdown 文件 50,000 个硬限制与抽题池截断上限，分享超大 Markdown 题库给他人时可完整索引并全库抽题

## 升级说明

- 覆盖安装即可（或在应用内点击「检查更新」自动更新），学习数据与题库不受影响
