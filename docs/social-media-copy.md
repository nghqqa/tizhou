备考这段时间，刷题 App 用了个遍：广告、会员、弹窗，做过的每道题都躺在别人服务器里🔒
后来干脆接手了一个 MIT 协议的开源公考工作台来维护，一路加功能、修体验，把它打磨成了现在的 **「题舟」**——今天正式开源出来，免费。

它能做什么👇

📕 **题本 PDF 直接入库**：纸质题本的扫描件也行，内置本地 OCR，自动切题、按题号配答案、去重，人工抽查确认后才入库
📚 **真题原卷模考**：我把自己收集的 2022–2026 国考/省考真题全导了进去，按原题号整卷组卷、限时作答、交卷自动出成绩单
✏️ **行测专项训练**：顺序 / 随机 / 自适应三种模式，做到一半关掉软件，下次接着来
🔁 **错题间隔复习**：答错自动进复习队列，记录错因，AI 还能把这道题给你讲透
📝 **申论作答**：草稿自动保存，AI 评估 + 规则评分双保险
📊 **学习报告**：正确率、能力画像、训练节奏，练没练全写在脸上

最重要的一点：**完全本地运行**。
数据存在自己电脑里，无广告、无推送、无遥测；AI 是可选项，不配模型照样完整刷题，配了也只在你主动使用时才会调用。

## 三、技术社区版（V2EX / 知乎 / 即刻）

**标题**：基于开源项目二创的本地优先考公工作台「题舟」，正式开源（Electron + React + SQLite + RapidOCR）

**正文**：

如题——仓库：https://github.com/nghqqa/tizhou （MIT 协议）

先交代血缘：题舟起初是对 MIT 开源项目「砺知考公工作台」的二创维护（已获原作者同意），历经 v0.4 → v1.0.5 的持续开发与品牌演进，现在是独立维护的开源项目，LICENSE 中保留了两代贡献者的版权行。

起因是自己备考时受不了两类产品：云端题库 App 的广告与锁定，和「上传你所有资料」的 AI 学习产品。所以题舟的原则始终是本地优先：

- **数据本地**：学习记录存本机 SQLite，题库是 Markdown 文件，随时备份迁移；无遥测、无广告、无推送
- **题库直导**：题本/解析/答案册 PDF 同批导入，扫描件走本地 OCR（RapidOCR，PP-OCR 同源 ONNX 模型，完全离线），自动切题、按题号配答案、去重；疑似套号错位整书拦截，切题结果先审核再发布
- **训练闭环**：行测顺序/随机/自适应训练、真题原卷整卷限时模考、错题分级间隔复习、申论草稿 + 评估
- **AI 可选**：模型和 API Key 用户自选（DPAPI 加密存储），不配置也能完整使用；AI 产物必须人工审核才会进入题库

技术栈：Electron 43 + React 19 + Fluent UI 9，electron-vite 构建，Vitest 91 项测试（含真实 OCR 集成测试）。

不分发任何题目内容（版权原因），内置示例题库仅供体验。欢迎试用、提 Issue、PR，觉得不错给个 Star⭐
