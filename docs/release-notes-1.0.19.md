# 题舟 v1.0.19

修复套题类解析册导入时目录页把套号推错位、导致整书触发「疑似套号错位」被拦截的问题。

## 题库直导修复

- **解析册目录套标题过滤修复**：解析册书首目录各套标题仅隔页码换行，而正文各套相隔上百行、各自形成孤立标题簇；`stripTocSetTitleRuns` 现汇总后文全部簇的套号判断目录重现，不再漏删目录而把 `setNo` 推高错位
- **分册首套标题边界保护**：分册书（如下册目录到第 30 套结束、紧邻正文第 16 套开始）聚簇时按套号非递增强制切簇，避免把正文第一套标题一并吞进目录簇删除
- **实测效果**：《2025年花生片段阅读600题》上下两册从全书拦截（0 产出）恢复为正常切出 546 题配对入库（上册 288 题 0 错位，下册 258 题仅 1 题错位）；既有质量基线解析册答案同步恢复 +21 条

## 测试

- 438 → 441 项单元测试（新增解析册目录过滤、分册首套边界与小夹具保护 3 项回归用例）；24 项真实 Electron E2E 保持通过

## 升级说明

- 覆盖安装即可（或在应用内点击「检查更新」自动更新），学习数据与题库不受影响
- 此前曾被「配对校验拦截（疑似套号错位）」拦截的套题类资料，升级后在知识库工坊重新点击「开始导入」即可正常切题入库（保留转换缓存，无需重复耗时 OCR）
