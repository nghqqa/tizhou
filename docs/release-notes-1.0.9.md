# 题舟 v1.0.9

资料分析与图形推理导入管线专项：图片保真、质量模型、能力边界收敛。

## 新能力

### 组题连续
资料分析「一组材料 + 5 道小题」整组抽取、组内连续，不再被随机打散；材料随每题保存，错题复习不受影响。

### 图表与表格保真
- 结构解析还原表格（含合并单元格 HTML 表格渲染）+ 图表裁剪为图片随题保存
- 解析册自动改道逐页 OCR，修复答案/解析串题；套内错位按内容相似度确定性校正（真实样本配对校验 0/15 → 19/20）
- 图片全链路贯通：任务缓存 → 审核 → 题库，缓存命中后图片引用不失效

### 导入质量模型（诚实降级）
- 每份资料标注能力边界：文字题·可自动导入 / 统计图·复杂表格·建议人工抽查 / 图片题·人工审核 / 图形推理图片题·暂不支持自动结构化 / 无法可靠结构化·仅保留原始资料
- 质量报告拆分维度：文字置信度、表格结构、图形区域、数字异常、水印剥离、配对校验——不再用「OCR 置信度 99%」代表整体质量
- 发布门禁：非文字题能力与「配对待确认」的产物默认禁止发布，需在审核详情勾选「我已查看原始页面并确认内容正确」后解除

### 解析清洗
- 水印剥离（只删宣传片段，出处/年份/地区不动，剥离数审计）
- 圆圈数字分类：句中保留为步骤编号，孤立标记移入审计块
- 数字串隔离：无语义数字流以审计块保留原数字，公式与带单位数字不误伤
- 段落重建与可读性检查（断句/括号未闭/只剩数字符号）

## 其他修复
- 解析册每套末尾「【全篇答案】」不再混入最后一题解析
- OCR 波浪线（≈）不再触发删除线渲染
- 共享材料级警告只在每组第一题显示一次

## 能力边界（重要）

题舟不会自动猜测图形规律、图表数字或图片选项：
- 扫描统计图的数字/图例结构、复杂合并单元格、扫描水印污染——保留原图与 OCR 文本，请人工对照核验
- 图形推理默认逐页保留原始页面，不做自动规律判定（实验性绑定默认关闭）
- 配对待确认的题目发布前必须人工核对
