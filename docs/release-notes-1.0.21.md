# 题舟 v1.0.21

优化扫描版与带水印 PDF 的本地 OCR 识别效果，并自动过滤跨页重复的页眉 Logo 与二维码干扰。

## 识别与导入优化

- **自适应去水印与去底灰（逐页 OCR 通道）**：漂白浅灰斜向水印与浅彩水印、增强深黑印刷体对比度，同时保护蓝色标题与亮红重点字等彩色印刷正文；仅作用于识字输入，不影响切图与原页证据图
- **提升逐页 OCR 渲染清晰度**：渲染 DPI 由 200 提升至 260，改善小字号编号、小数点与负号识别
- **页眉重复小图自动剔除**：结构解析后处理按坐标与尺寸容差聚类识别跨页重复的页眉 Logo / 二维码并自动剔除，保留正文大图与页顶独立题目小图
- **缓存自动刷新**：升级转换缓存策略键，已导入过的 PDF 重导时自动启用新版 OCR 策略

## 升级说明

- 覆盖安装即可（或在应用内点击「检查更新」自动更新），学习数据与题库不受影响
