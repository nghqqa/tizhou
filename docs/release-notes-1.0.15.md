# 题舟 v1.0.15

导入管线系统性修复与核心体验闭环：图形推理选项图自动绑定并直显、知识工坊发布门禁闭环、模考逐题复盘、大题库组卷不再截断、统计跨零点错位修复。

## 导入与图形推理

### 题号漂移修复

- 悬挂缩进 PDF 的文字流把题号挤进题干中间（"坚持以人民为中1.心"）或上一段行尾（"…云服务、114."）：按下一个期望题号在行中/行尾找到并归位，来源页行号映射不受影响
- 题干里的顿号数字枚举（"10、11、12"）不再被误判为题号；漂移题号不拼到套标题等结构行上

### 混合卷图推几何绑定

- 行测整卷中的图形推理小题：按版面坐标把 A-D 选项图自动绑到题目上（标签与图片水平对齐 + 垂直最近）
- 多套卷同文件：锚点按"套-题"键控并按题号回落划分卷段，第二套不再映射回第一套版面，跨卷不误吞同号锚点
- 行首题号缺失（漂移）时按块内漂移题号或题干前缀兜底定位，上一题的图片边界同步修正
- 双栏试卷按"左栏→右栏"阅读顺序排序；"1.5亿元"等小数行不再误判为题号锚点
- 凡绑定产生提示的图推题一律进人工核对，不自动发布

### 批次资产与去重

- 同批多文件导入共用图片目录时不再互相清空，所有图片完整随发布入库
- 资料分析的共享材料参与去重签名：重复导入带材料题不再漏判

## 知识工坊：发布门禁闭环

- 未人工确认的高风险产物（图形推理 / 图片题 / 配对待确认）发布时被严格拦下，保持已批准状态不入库，提示如实
- 已批准未确认的产物可在详情页直接补交「人工确认」，批量批准造成的死锁消除
- 发布入库只拷贝图片文件，`_regions.json` 等转换 sidecar 不再混入题库

## 模考：逐题复盘与大题库

- 交卷后逐题复盘：你的作答 vs 参考答案（含图片选项对照）、判分对错、参考解析，可筛「仅看错题与未答」，附模块正确率分布
- 历史模考随时回看：已交卷进复盘页，进行中的继续作答
- 原卷组卷不再受 5000 题列表截断：万题级题库的旧年份真题卷完整入卷；练习抽题池同口径放开
- 题量不足 30 的卷不出现在列表（口径与组卷一致）；有未完成模考时两种开考入口都禁用
- 中途切换/重索引题库后交卷不再卡死：作答照常落盘，错题登记只针对仍存在的题目

## 练习与界面

- 组合筛选：科目 / 模块 / 年份 / 地区 / 试卷 / 难度 / 关键词任意组合，支持只练错题、只练收藏
- 整组汇总解析逐题对照你的选择与参考答案；重启后恢复会话不丢已答记录
- 图形推理图片选项在作答区与复盘区直接显示（纯图、图文混合均可）
- 收藏按钮有状态反馈、可取消；AI 变式与申论页统一 Markdown 渲染；申论题支持关键词检索
- 焦点在下拉框/按钮上时 Enter 不再误触提交

## 修复

- 北京时间 00:00-08:00 的作答此前会被统计到前一天（UTC 日期切片）：今日完成、训练日历、连续学习天数、报告日切分、自动备份当日去重全部改为本地日期口径
- 恢复备份后重新挂载知识库磁盘监听

## 测试

- 306 → 335 项单元测试，新增 21 项 E2E（含图形图片选项到逐题复盘的全链路用例）

## 升级说明

- 覆盖安装即可，学习数据与知识库不受影响
- 升级后首次在知识工坊「发布」时，此前被误发布的未确认产物如需清理，可用该任务的「撤销导入」回滚后重新审核发布
