# 题舟 v1.0.41

全面补齐贴合考生真实作答习惯的实用工具：申论材料勾画摘录、答题卡缩进与单题计时、行测手写草稿纸及本场错题重刷。

## 新特性与改进

- **申论材料荧光笔与一键摘录**：支持黄/绿/蓝/红四色高亮、连画模式、单击取消与自动持久化；划词后可点 `+ 摘录` 直接标黄并追加到右侧作答草稿
- **申论单题计时与段首空两格**：新增单题计时提醒（小题 20 分钟 / 作文 60 分钟）；方格答题卡支持 `Tab` 键与「空两格」按钮一键段首缩进
- **行测随手草稿纸**：专项练习与模拟考试可随时呼出轻量草稿浮层，支持手写涂鸦（黑/红双色笔）与速算便签
- **本场错题一键重刷**：专项练习结算页支持直接重刷本组错题，趁热巩固

## 升级说明

- 覆盖安装即可（或在应用内点击「检查更新」自动更新），学习数据与题库不受影响
