# 题舟 v1.0.43

修复申论作答页中文打字筛选时输入框消失及误触发空状态的问题，并统一升级全站搜索的输入法保护与多词检索能力。

## 新特性与改进

- **申论作答页常驻筛选栏与中文输入法保护**：拼音输入选词期间不再用未上屏拼音触发查库；检索无结果时仅在下方作答区显示空状态提示，保留地区选择与关键词输入框以便直接修改；消除清空筛选时的空库误报闪烁与 0 题型 Tab 回退显示旧题问题
- **全站多词 AND 检索与范围扩展**：支持以空格分隔输入多个关键词联合搜索，并将给定资料、试卷名、地区、年份、教材来源与文档标签纳入检索，同时转义 `%` / `_` 通配符；为全站搜索框补齐一键清除按钮，并修复全局检索面板点击申论主观题跳转路由错误

## 升级说明

- 覆盖安装即可（或在应用内点击「检查更新」自动更新），学习数据与题库不受影响
