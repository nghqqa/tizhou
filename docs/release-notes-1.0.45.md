# 题舟 v1.0.45

修复申论作答页顶部选题器右侧越界问题，优化给定资料居中精读排版与阅读字号缩放体验。

## 新特性与改进

- **修复顶部「选择题目」右侧越界**：限制三列筛选网格及弹窗触发器内部容器的最小宽度与溢出裁切，长题干稳定省略显示，下拉题目列表改为右对齐避免溢出视口
- **材料居中精读与「作答要求」卡片化**：给定资料正文按 `760px` 适读宽度居中展示，底部题干改为带「作答要求」标签的独立纸面卡片并与材料正文边缘对齐
- **阅读字号缩放与界面紧凑优化**：修复「申论阅读」字号滑块与「公文体」未同步作用于材料正文、题干放大过大的问题；将题型与材料完整度筛选条合并展示，并过滤与试卷名重复的教材来源标签

## 升级说明

- 覆盖安装即可（或在应用内点击「检查更新」自动更新），学习数据与题库不受影响
