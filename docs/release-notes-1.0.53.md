# 题舟 v1.0.53

基于主流公考教辅真实扫描 PDF（覆盖花生十三、四海、酷酷刷、夸夸刷及行测全五科与申论）完成 OCR 引擎与直导解析链路深度优化，显著提升切题完整度、解析配对准确率与图文还原质量。

## 核心优化与修复

- **OCR 引擎去噪、双栏分离与提速**：修复边缘去噪误挖正文年份/表格数值，新增左右交替边栏批注分离（解析册正文不再被批注交错污染），保护高频 `【参考答案】` 等解析结构标签免遭跨页去重误删，实现 `--structured` 精确逐行页码映射与纯文字层 PDF 快路径
- **图形推理全题恢复**：新增组合选项图回退、3 缺 1 几何补全、九宫格表格图原图抢救、文字选项图推裁界与多分段答案表解析，实测主流图推教辅 61 题零丢题
- **资料分析与解析配对加固**：支持同套多篇材料精准切分与 D 选项后表格/配图/数据段自动隔断，修复单行资料分析题干解析对齐误拦，适配四海独立答案册按段名配对与夸夸刷/酷酷刷例题及内嵌答案，升级跨行跨列 HTML 表格质检
- **申论、言语与判断全链路适配**：申论直导全面兼容 `--structured` `#` 标题、内联真题年份/省份提取与虚线名言框清洗；言语理解自动拆分 D 选项粘连的下一题、支持篇章阅读跳号续切与 `# 答案对照表` 识别；Vitest 测试扩充至 590 项全量通过

## 升级说明

- 覆盖安装即可（或在应用内点击「检查更新」自动更新），现有学习记录、错题本、笔记本与本地题库不受影响
- OCR 转换缓存策略升级至 `p6`，已导过的 PDF 再次导入时将自动采用新策略重解析
