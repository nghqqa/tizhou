# 题舟 v1.0.46

锁定「资料分析」整套 5 题连续有序出题并修复跨模块混组问题，上线 AI 流式输出、专注模式、快捷键速查与增强草稿纸等七项交互体验升级，并完成前后端模块化架构重构。

## 新特性与改进

- **资料分析 5 题连续锁死与跨模块混组修复**：组题键强制隔离模块分类与完整材料哈希，修复不同模块 `groupId` 碰撞引发的交叉出题与多小题标签页异常；随机与自适应抽题严格按整套 5 题连续顺序（`1→2→3→4→5`）抽取并过滤残题，训练配置自动按 5 的倍数对齐题数，同步修复导入脚本 `groupId` 哈希碰撞
- **AI 流式打字机输出与随时停止**：AI 助教、刷题即时解析、能力诊断与申论 AI 批改全面接入实时流式输出（支持 OpenAI Chat / Responses、Anthropic、Gemini 四套协议），可随时点击停止保留已生成内容
- **沉浸专注、全屏与快捷键速查**：新增沉浸专注模式（`Alt+Z`）与 `F11` 全屏切换，一键收起侧栏导航；按 `?` 呼出按当前页面分组的快捷键速查浮层，补齐标待查（`U`）、草稿纸（`S / Alt+D`）与申论切题/保存快捷键
- **行测体验与题库细节升级**：新增行测材料/题干四色荧光笔、单选/判断「极速连刷」、相似题可作答自测与一键追加进本组、单题就地勘误写回源 Markdown（单题增量重索引），以及内置速算器与多色/橡皮/缩放撤销画板的增强草稿纸
- **模块化架构重构与回归保障**：主进程 IPC / 数据库仓储 / 知识库流水线与渲染层页面样式完成模块化拆分，新增流式、勘误、速算与资料分析锁定等专项单元测试

## 升级说明

- 覆盖安装即可（或在应用内点击「检查更新」自动更新），学习数据与题库不受影响
- 若此前存在尚未做完的资料分析旧训练会话，点击一次「放弃并新建」重新生成训练即可按新规则锁定 5 题连续出题
