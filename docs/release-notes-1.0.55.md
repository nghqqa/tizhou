# 题舟 v1.0.55

围绕国省考申论真考阅卷细则全面升级主观题评分引擎与 AI 批改协议，并修复示范作答文本中残留字面 `\n` 的换行渲染问题。

## 核心优化与修复

- **申论真考评分细则与客观核查**：新增 [shenlun-rubric.ts](src/shared/shenlun-rubric.ts)，按归纳概括、提出对策、综合分析、贯彻执行、文章写作五类细分题型差异化赋权，自动提取题面满分与字数区间，按公文全格式/半格式/弱格式/格式豁免四级分级核查（简报、提纲、调研报告等不再误扣称谓和落款），并联动 25 格实考占格与材料照搬率检测
- **大作文分档校准与离线评分重构**：大作文引入一/二/三/四类文定档与残文/大面积照搬硬封顶，题面按半分粒度折算并展示于评估结果栏；离线本地规则评分同步修复大作文 >500 字误扣，支持从参考解析抽取要点并以实词词元比对踩点情况
- **批改结果换行修复（含历史记录）**：在入库解析与前端展示层双端还原模型双重转义的 `\r\n`/`\n`/`\t`，新生成的示范作答与已保存的历史评估记录均正常分段换行；Vitest 单元测试扩充至 602 项全量通过
