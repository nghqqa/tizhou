# 题舟 v1.0.20

调整知识库工坊审核状态徽章语义色，消除「待审核 / 等待审核」与报错警示撞色导致的视觉压迫感。

## 界面优化

- **待审核 / 等待审核**：由深红实心胶囊调整为柔和琥珀浅底与细描边，表达「等待确认」的正常中间态，不再抢占题干、警告与选中态的视觉焦点
- **已批准 / 已发布 / 本批已处理**：调整为松烟绿浅底与细描边，清晰区分已通过与待审核项
- **已拒绝 / 已取消**：采用淡墨灰描边退居次级，避免干扰待审核项浏览
- **任务异常 / 进行态**：仅「任务异常」保留朱砂红实心提示，等待启动与处理中采用温润暖灰底，浅色/深色双主题同步适配
