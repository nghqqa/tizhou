# 题舟 v1.0.52

集中完成主进程安全与数据库持久化、AI 网关与申论批改、模考刷题交互、知识库工坊与自动更新的全链路稳定性修复，并精简安装包依赖体积。

## 稳定性修复与改进

- **主进程安全与数据持久化**：修复 Windows 中文路径迁移复制崩溃与老库升级索引顺序，加固目录打开白名单与备份回滚句柄释放，严格按活动知识库与科目隔离工作台统计及原卷查询
- **AI 网关与申论批改**：增强 SSRF 防护与切换服务商自动清凭据，完善非流式请求取消与截断提示，加固申论评分 JSON/Markdown 容错解析与格子纸满行换行、输入法组合键体验
- **模考、刷题与导出体验**：拆分模考主客观保存队列并防止重复交卷，模考结果页申论题改为中性展示不污染错题本；修复重刷错题、题单分页、选项图内嵌与无答案试卷 PDF 笔记保留，完善行测估分子分类归并
- **知识库工坊、自动更新与安装包瘦身**：补齐并发任务锁、DML 安装失败回退 CPU、自动更新回退 GitHub 源重置；剥离冗余前端打包依赖减小安装包体积；单元测试扩充至 570 项全量通过
