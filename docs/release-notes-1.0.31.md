# 题舟 v1.0.31

重点优化 5 万题级大型题库的增量重索引性能，并扩展本地格式转换工具链。

## 新特性与改进

- **大题库增量索引提速**：重索引改用轻量元数据列比对（不再全量读入长材料和解析），结合文件 `mtime + size` 零读盘快速跳过未修改文件，大幅降低大题库重索引耗时与内存占用
- **格式转换工具扩展**：`tools/direct-import.mjs` 新增 `xingcezhenti` 与 `kaogong-shuati-shenlun` 转换子命令，支持本地格式转换、来源标识写入与跨库去重

## 升级说明

- 覆盖安装即可（或在应用内点击「检查更新」自动更新），学习数据与题库不受影响
