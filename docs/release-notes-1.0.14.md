# 题舟 v1.0.14

知识库增量索引与磁盘变更自动重索引、直导工具链核心拆分与单元测试。

## 性能

### 增量索引

- 按「文件路径 + 内容哈希」复用库中记录，内容未变的文件不再重新解析
- 2.2 万题真实库实测：首次全解析 8.5 秒 → 二次增量 2.4 秒
- 索引快照改为整库一次查询；未变的题不再全量重写（大库重索引在应用内的主要耗时）
- 无变更的重索引不产生快照，不堆积冗余

### 磁盘监听自动重索引

- 递归监听活动知识库目录，Markdown 变动后 3 秒防抖自动增量重索引
- 导入脚本批量落盘只触发一次；外部编辑器改题无需手动点「重新索引」
- 窗口重新获得焦点时自动对齐侧栏计数（新增 `vault.active` 请求）
- 设置页索引结果显示「未变复用 N」

## 重构

- 直导工具链核心（Markdown 契约 / 三级去重签名 / 申论材料定位 / 字段解析）拆到 `tools/lib/import-core.mjs`
- 新增 14 个单元测试：`\w` 不含中文、材料引用边界、papers 回填幂等、frontmatter 读回一致性等
- 真实导入回归：转换计数与拆分前逐项一致

## 测试

- 288 → 306 项：增量索引行为（无变更全复用 / 单文件改动 / 移动与删除）、磁盘监听自动入索引、真实库基准（`VAULT_BENCH_DIR` 门控）

## 升级说明

- 覆盖安装即可，学习数据与知识库不受影响
- 首次启动后的第一次「重新索引」为全量解析，之后即走增量
