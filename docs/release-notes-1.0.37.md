# 题舟 v1.0.37

全面升级申论 AI 评估提示词，针对无官方答案真题与四大申论题型实现精准分型批改。

## 新特性与改进

- **无官方解析真题智能提炼评分**：当题目暂无官方参考答案时，AI 会先依据题干与给定材料独立提炼采分点再按点批改，并直接输出符合字数/格式要求的「参考思路/示范作答」
- **四大题型差异化评分与精确字数核查**：自动传入题型（单一题 / 综合题 / 公文题 / 作文题）与精确字数统计，公文题核查格式与口吻，大作文重在立意与论证，并在总结中附带题面满分折算分

## 升级说明

- 覆盖安装即可（或在应用内点击「检查更新」自动更新），学习数据与题库不受影响
