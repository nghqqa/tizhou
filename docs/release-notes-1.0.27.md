# 题舟 v1.0.27

面向高频刷题、模拟考试、错题复盘与知识查阅的全链路体验升级。

## 新特性与改进

- **专项练习提效**：新增「只练未做」筛选、单题实时计时器（超 60 秒提醒，点击切换显隐）、右键选项排除法、右栏「本组答题卡」跳题回看与「上一题」导航、`summary` 模式未答题循环推进
- **模拟考试增强**：新增右键选项排除法、「标记不确定」待查标旗、交卷弹窗同时提示未答与待查数，并支持 `1–8 / A–H`、方向键与 `U` 快捷键
- **错题本 / 我的收藏 / 我的笔记全景库**：错题复习页升级为 4 Tab，支持按模块、错因与关键词全景筛选、展开解析、行内编辑保存笔记，以及「针对当前筛选练错题 / 练收藏」一键开刷
- **知识中心全文检索、目录与自由排版**：搜索支持命中正文上下文片段预览，自动生成二级/三级标题目录平滑跳转，并接入题目区同款自由放缩与字体定制工具条
- **申论字数红线预警 & 目标考试倒计时**：自动识别题干字数上下限并标示超字/不足预警；首页顶部新增可点击行内编辑的目标考试倒计时（与设置页双向同步）

## 升级说明

- 覆盖安装即可（或在应用内点击「检查更新」自动更新），学习数据与题库不受影响
