# 题舟 v1.0.13

题库导入器扩展（kaogong 快照 / OpenExam 整卷 JSON）、近重复扫描工具、AI 行为约束与评测骨架、AI 消息 Markdown 渲染修复。

## 新能力

### 导入器扩展（渠道二直导工具链）
- `build kaogong`：kaogong 快照 SQLite 一键转知识库，默认行测真题，附时政/申论真题/素材；卷库题序映射后直接可用「真题原卷模考」
- `build openexam-json`：OpenExam 整卷 JSON 目录转换；`--material-db` 从种子库接回资料分析材料，`--assets-dir` 拷贝材料统计图
- 三级跨库去重：严格签名 → 宽松签名 → 资料分析题干包含；主库为准、新库只补增量
- papers 回填：重叠题自动并入新卷归属（只追加），每次操作写 JSONL 台账，可回溯可撤销
- 申论材料定位：按题干引用抽取对应「材料N」段落，引用不明确时回退全文

### 题库治理工具
- `npm run dedup:scan`：simhash 分带 + Jaccard 精排的近重复扫描，产出报告与簇台账（open/resolved/ignored），只检测不改库

### AI 行为约束与评测
- 错题讲解三条红线：题目存疑 fail-closed / 答案一致性 / 与参考答案分歧时明确说明
- 申论批改：子项级采分点核对、命中四级分级、【缺：×××】点名遗漏关键词、踩点给分不倒扣
- `npm run eval:ai`：固定题集离线评测线上 prompt（契约符合率/答案命中率/关键词引用率/红线违规），结果落盘 JSON

## 修复

- AI 助教回答、AI 变式训练解析、申论参考解析此前按纯文本显示，现统一用 Markdown 渲染（列表/加粗/表格/代码块正常显示）
- 聊天气泡空白处理与 Markdown 排版冲突修复

## 升级说明

- 覆盖安装即可，学习数据与知识库不受影响
- 新增命令均为可选工具，不影响既有使用方式
