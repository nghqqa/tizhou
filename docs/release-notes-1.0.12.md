# 题舟 v1.0.12

来源页证据与原页预览、导入质量分级、模考保存修复。

## 新能力

### 来源页证据与原页预览
- 每个导入产物标注「来源 第N页」，题本页/材料页/解析册页分别记录
- 审核页点击按钮弹出原 PDF 页截图预览（翻页/缩放/关闭）
- 无法定位页码时显示「暂无法定位原页」，不猜页码
- 证据图片存任务独立目录，清空转换缓存后仍可查看

### 导入质量分级
- 三级分层：结构化题目 / 待人工审核 / 原始资料保留
- 批次消息显示真实计数（文件数/页数/跳过数），不用题目数推算
- 非「文字题」产物默认禁止发布，需人工确认后解锁

### 缓存管理
- 知识库工坊支持按文件清除转换缓存
- 「忽略缓存重新转换」选项
- 缓存统计面板

## 修复

- 模考快速连续点选项后立即交卷不再丢失（drain 在途竞态修复）
- 单页渲染崩溃不再白屏整个应用（错误边界）
- 迁移安全加固（路径穿越/符号链接逃逸/损坏数据库全部拒绝）

## 其他
- OCR Benchmark 入库（40+ PDF 真实样本清单、三引擎指标）
- 单元/集成测试 287 项；UI E2E 20 项

## 能力边界

题舟不会自动猜测图形规律、图表数字或图片选项。confirmed Ground Truth = 0。structured 不代表 OCR 内容正确。不报告真实 OCR 准确率/召回率/缺题率。
