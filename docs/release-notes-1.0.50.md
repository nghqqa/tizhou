# 题舟 v1.0.50

聚焦申论考场实战还原度与 AI 批改稳定性，升级申论方格答题卡实考占格规范，并全面加固申论 AI 批改防回退机制。

## 新特性与改进

- **申论答题卡实考占格规范**：阿拉伯数字与连续字母升级为「两位一格」，小数点、百分号与题号智能贴附不单占格；行首标点自动行尾挤格，破折号（`——`）与省略号（`……`）双格不断行，已占格数、标尺刻度与字数限制提示更贴合真实考场体验
- **申论 AI 批改稳定性加固**：自动识别并剥离推理模型思考过程（`<think>` / Google `thought` 块），兼容并自动修复模型输出中常见的裸换行、未转义双引号、尾逗号及轻度截断 JSON，必要时智能抢救完整 Markdown 批改正文
- **输出预算保护与自适应重试**：为申论批改提供 `4096`–`8192` `maxTokens` 下限保护与流式空闲超时保护；流式异常时自动切换非流式重试、超长材料精准收敛，并新增醒目的 AI 回退原因提示与一键「重新用 AI 批改」按钮

## 升级说明

- 覆盖安装即可（或在应用内点击「检查更新」自动更新），现有学习记录、错题本、笔记本与本地题库不受影响
