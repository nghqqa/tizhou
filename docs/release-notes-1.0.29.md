# 题舟 v1.0.29

新增地方性三栏级联地区分类、教材来源独立标识、申论按需加载与包体积瘦身优化。

## 新特性与改进

- **三栏地区级联选择器**：申论作答、专项练习与模拟考试接入无遮罩悬浮三栏面板（考试大类 → 地区与题量 → 当地题目/试卷），自动防溢出对齐并记忆目标考区，消除页面加载抖动
- **申论地区分类与老库一键整理**：申论直导自动提取地区；同义地区（如 `北京` / `北京市`）自动归并；「学习环境」新增「整理地区标签」按钮一键规范旧题库
- **教材来源标识**：申论作答与专项练习页元信息栏单独展示 `教材来源：...`，区分专项教材与各地真题
- **性能与体积优化**：补齐数据库地区/年份/试卷复合索引与 `facets` 缓存；申论材料按需加载；剔除冗余 KaTeX `.woff`/`.ttf` 字体；「应用设置」支持一键清理 OCR 转换缓存

## 升级说明

- 覆盖安装即可（或在应用内点击「检查更新」自动更新），学习数据与题库不受影响
