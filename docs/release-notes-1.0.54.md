# 题舟 v1.0.54

修复专项练习页面中模块下拉题数与地区等筛选条件未联动导致的假有题报错，并自动补全多源合库中缺失地区标签的真题。

## 核心优化与修复

- **入库与存量题库地区自动补齐**：题库索引与地区整理新增从 `papers` / `papers_json` 及 `sourceFile` 提取考试地区（如国考），并在应用启动时通过幂等数据库迁移自动回填存量题库缺失的地区字段（无需手动重新导入）
- **专项模块、年份与筛选条件实时联动**：「专项模块」下拉框题数实时跟随当前科目、地区、年份、试卷、难度、关键词及只练未做/错题/收藏状态更新，「全部模块」同步显示当前可用总题数；年份下拉列表按地区级联过滤，切换条件时自动清除已失效的模块与错误提示
- **跨题源二级模块兜底抽题**：在选中如「判断推理-图形推理」等二级细分模块且当前地区下仅存在一级大模块归类题目时，自动按标签兜底匹配对应子题型（资料分析继续严格锁定 5 题整套材料，不拆散）；Vitest 测试扩充至 596 项全量通过

## 升级说明

- 覆盖安装即可（或在应用内点击「检查更新」自动更新），现有学习记录、错题本、笔记本与本地题库不受影响
- 升级后首次启动将自动在本地完成存量题库缺失地区的回填，无需重新扫描或导入原题库目录
