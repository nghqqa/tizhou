# 题舟 v1.0.48

聚焦备考辅助手写体验与官网透明演进：行测「随手草稿纸」支持自由拖动、四角停靠与记忆位置，官网上线实时联动的「更新日志」专栏。

## 新特性与改进

- **行测随手草稿纸自由拖动与快捷停靠**：在专项练习与模拟考试中按住草稿纸顶栏或左侧六点抓手即可任意拖动（自动防拖出屏幕、支持视口缩放重定位并记忆上次位置）；点击抓手可一键停靠屏幕四角，双击顶栏或按 `Home` 快速复位至右下角；聚焦抓手支持方向键微调（不触发外层切题快捷键）
- **官网新增「更新日志」专栏**：官网直接解析项目 `CHANGELOG.md`，提供关键词多词检索、按行测/申论/知识库/AI 主题筛选、版本索引直达与历史版本折叠浏览

## 升级说明

- 覆盖安装即可（或在应用内点击「检查更新」自动更新），现有学习记录、错题本、笔记本与本地题库不受影响
