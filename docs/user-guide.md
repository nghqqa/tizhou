# 题舟用户指南

## 安装说明

### 系统要求

| 项目     | 最低要求                                     |
| -------- | -------------------------------------------- |
| 操作系统 | Windows 10 1809+ / Windows 11                |
| 处理器   | 64 位 Intel/AMD 双核                         |
| 内存     | 4 GB（推荐 8 GB）                            |
| 硬盘     | 500 MB（应用）+ 200 MB（OCR 引擎）+ 题库空间 |
| 网络     | 安装引擎和检查更新时需要；日常使用可完全离线 |

### 安装步骤

1. 从 [GitHub Releases](https://github.com/nghqqa/tizhou/releases) 下载 `tizhou-setup-X.X.X.exe`
2. 双击运行；Windows SmartScreen 可能提示"未知发布者"，点击"更多信息→仍要运行"
3. 选择安装路径（默认 `%LOCALAPPDATA%\Programs\tizhou`）
4. 安装完成后自动创建桌面快捷方式

### 首次启动

1. 应用启动后显示内置示例题库，可直接体验训练/模考功能
2. 要使用完整功能，进入 **知识构建** 页面安装转换引擎（含 OCR，约 200 MB）
3. 要使用 AI 功能，进入 **模型设置** 配置 API Key（可选，不装也能刷题）

### 卸载

- 控制面板→程序→卸载"题舟"
- **卸载不会删除用户数据**（学习记录、题库、API Key 均保留在 `%APPDATA%\tizhou`）
- 如需彻底清理，手动删除 `%APPDATA%\tizhou` 目录

## 数据存储位置

| 数据                     | 位置                                                |
| ------------------------ | --------------------------------------------------- |
| 学习记录、设置、题库索引 | `%APPDATA%\tizhou\workbench.sqlite`                 |
| 自动备份                 | `%APPDATA%\tizhou\backups\`                         |
| OCR 转换引擎             | `%APPDATA%\tizhou\knowledge-builder\engine\`        |
| 应用管理题库             | `%APPDATA%\tizhou\knowledge-builder\managed-vault\` |
| 用户连接的题库           | 用户自选目录（如 `E:\tizhou-vault`）                |

## 备份与恢复

### 自动备份

应用每天首次启动时自动创建数据库备份（默认保留 12 份）。

### 手动备份

1. 进入 **应用设置→数据备份**
2. 点击"立即备份"
3. 备份文件保存在 `%APPDATA%\tizhou\backups\`

### 恢复备份

1. 进入 **应用设置→数据备份**
2. 在备份列表中点击"恢复"
3. 恢复前会自动创建 pre-restore 快照，可撤销

### 跨机迁移

1. 旧机器：**应用设置→跨机迁移→导出迁移包**（包含学习记录+题库）
2. 拷贝迁移包到新机器
3. 新机器：安装应用→**跨机迁移→导入迁移包**
4. API Key 需在新机器重新填写（加密密钥不随包迁移）

## 隐私说明

- **本地优先**：所有学习数据存储在本机，不上传任何服务器
- **不上传题库**：你导入的 PDF/Word 资料只在本机转换和存储
- **API Key 安全**：使用 Windows DPAPI 加密存储，不写入明文文件
- **AI 可选**：仅在主动使用 AI 功能时调用你配置的模型服务
- **无遥测**：应用不收集任何使用统计或诊断数据
- **检查更新**：仅访问 GitHub Releases 获取版本信息，不发送个人数据

## 常见问题

### 安装时 SmartScreen 提示"未知发布者"

应用未购买商业代码签名证书。点击"更多信息→仍要运行"即可安全安装。

### OCR 转换引擎安装失败

确认系统已安装 Python 3.10+（从 [python.org](https://www.python.org/) 下载，勾选 "Add to PATH"），然后重新点击"安装转换引擎"。

### API Key 在新机器上无法使用

API Key 使用 Windows 用户级加密（DPAPI），换机器/用户后需重新填写。这是安全设计。

### 模考中途关闭应用，答案会丢失吗？

不会。选择题每次作答立即保存；主观题 600ms 自动保存；重新启动后从上次进度继续。
