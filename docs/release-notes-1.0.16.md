# 题舟 v1.0.16

知识工坊新增可选 VLM 多模态按页精校闭环：视觉模型辅助核对 OCR 表格与数字，人工「编辑正文」与精校建议双向同步；同时修复四处实机界面细节，并把验证覆盖扩充到 363 项单元测试与 24 项真实 Electron E2E。

## 知识工坊：可选 VLM 多模态按页精校

### VLM 按页精校（可选，默认关闭）

- 审核详情对含来源页证据的产物提供「VLM 按页精校」：把触发精校的 PDF 页面高清图发送到你配置的视觉模型，返回逐项核对建议；建议不落盘，对比后手动采纳
- 工坊顶部开关与模型设置联动：关闭时精校按钮随之隐藏，知识工坊保持 100% 本地离线
- 精校动作逐页容错：单页失败或超时不中断，未覆盖页与失败页在批次口径中如实呈现，页面图片引用缺失时自动保底跳过，不虚构核对结论

### 模型设置独立配置与探活

- 视觉模型支持「复用主模型」或「单独配置视觉模型」，兼容 DeepSeek OCR / 通义千问 VL 等视觉通道的 4 类协议适配（openai-chat / openai-responses / gemini / anthropic）
- 「测试视觉模型」在未开启配置时也可探活，且不翻转开关状态
- 视觉模型 API Key 与主模型一致，使用 Windows DPAPI 加密存储

### 人工「编辑正文」与发布对齐

- 产物详情可直接编辑 Markdown 正文（错别字、错数字），人工编辑与 VLM 建议采纳共用同一保存通道
- frontmatter 中的 id、参考答案与选项图片绑定服务端强校验不可篡改
- 正文修订经 gray-matter 统一解析同步回 frontmatter，发布写盘口径对齐

### 来源页对照

- 「来源页预览」浮层调出原始 PDF 页（上一页 / 下一页 / 放大 / 缩小），切分结果与原卷逐页核对

## 实机细节修复

- 知识工坊产物窄栏徽章（待审核 / 规则切题等）不再竖排折字，窄栏时整枚换行
- 含内嵌 Markdown 图片的图推题干，列表标题不再裸露「![](images xxxxx)」语法碎片
- 批次汇总消息移除内部调试前缀，直接以切题与审核引导开篇
- 申论页「选择题目」下拉在长题干下不再向右侧面板溢出压边

## 测试

- 335 → 363 项单元测试；21 → 24 项真实 Electron E2E，新增 VLM 开关持久化、工坊精校按钮联动显隐、人工编辑 UI 与磁盘双重持久化用例

## 升级说明

- 覆盖安装即可，学习数据与知识库不受影响
- VLM 按页精校默认关闭；如需使用，在「模型设置」开启并按需配置视觉模型，或直接复用已配置的主模型
