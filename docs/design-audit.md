# 设计审计与系统规范

## 模式

重构类型：新中式书房（Neo-Chinese Scholar's Desk）桌面端统一设计系统。

Design Read：面向长期备考者的本地桌面学习工作台，克制、温润、高信噪比、适合长时间精读与作答，结合 Fluent UI v9 组件基座与自定义 `--tz-*` 令牌系统。

- `DESIGN_VARIANCE: 4`
- `MOTION_INTENSITY: 3`
- `VISUAL_DENSITY: 7`

## 保留与核心原则

- 左侧学习 / 管理双分组固定侧栏，底部保留全局主题切换与检查更新入口。
- 首页、训练（专项练习 / 错题复习 / 模拟考试）、知识（知识库工坊 / 行测知识 / 行测方法 / 申论知识 / 申论方法 / 规律中心）、提升（申论作答 / 学习报告 / AI 助教 / AI 变式训练 / 能力诊断）、系统（学习环境 / 模型设置 / 应用设置）的清晰路由心智模型。
- 内容库、用户学习记录、AI 凭据与 Obsidian 集成相互隔离。
- 键盘导航、空状态引导、明确可操作的错误降级与可解释的学习诊断规则。

## 近期全站优化与演进

- **全站 CSS 令牌收敛**：所有 `--tz-*` 别名（含 `--tz-accent`、`--tz-paper`、`--tz-line`、`--tz-font-song` 等）均已在 `:root` 与深色主题统一定义，消除未定义变量回退导致的视觉漂移与暗色对比度不足。
- **宽屏与长读体验升级**：知识中心、AI 对话、知识库工坊与复盘报告采用 `min(1560px, 100%)` 宽屏网格，知识阅读正文字宽锁定 `820px`（约 40–45 汉字/行）并配备全站统一阅读字体/字号控制栏。
- **统一交互弹窗与反馈**：全站危险/重要操作统一采用 Fluent `<ConfirmDialog>`（高危重置要求输入确认短语），轻量提示统一走全局 Toast 与 `<ErrorState>`，彻底移除浏览器原生 `alert/confirm/prompt`。
- **可访问性与字号基线**：侧栏、命令面板（`role="listbox"` / `option` + 键盘跟随滚动）、级联地区选择器（动态防溢出定位）均保持语义无嵌套按钮、完整键盘可达，中文 UI 微型辅助标签统一不低于 `11px`（推荐 `12px` `--tz-text-xs`）。

## 设计锁

- **双色主题表面体系**：
  - 宣纸亮色：工作区背景 `#F5F1E8`，纸面卡片 `#FBF9F4`，次级表面 `#F0ECE2`，墨色主文本 `#282520`。
  - 灯下墨黑：工作区背景 `#1B1917`，内容卡片 `#24211E`，次级表面 `#2B2521`，暖白主文本 `#F0EAE1`。
- **双核心语义强调色**：
  - 主品牌强调色：朱砂红 `--tz-vermillion`（亮色 `#B84432` / 暗色 `#C65B43`）。
  - 辅助正反馈色：松石绿 `--tz-pine`（亮色 `#557363` / 暗色 `#739181`），预警琥珀 `--tz-amber`（亮色 `#B7863D` / 暗色 `#B68B4B`）。
- **圆角与版式**：小圆角 `4px`（`--tz-radius-sm`），标准控件 `6px`（`--tz-radius`），弹层/阅读容器 `8px`（`--tz-radius-lg`）；卡片边框优先、阴影克制。
- **文本规范**：UI 可见文案除受既有字数区间格式化约束外避免不必要的装饰符号。
