# 题舟 v1.0.33

优化申论材料阅读体验，新增材料分段切换与智能匹配推荐，并修复导入材料中的康熙部首异体字。

## 新特性与改进

- **申论材料分段导航与相关推荐**：在「申论作答」页自动识别 `材料1`、`材料2`… 分段，提供顶部快速切换标签与「全部 (N)」视图；非大作文小题自动高亮并默认定位到最相关的材料段
- **导入智能拆段与 NFKC 归一化**：`kaogong-shuati-shenlun` 转换器为非大作文小题智能匹配对应材料段（大作文仍保留整卷材料），并将 PDF 文本中的康熙部首异体字统一归一化为标准汉字，提升检索与匹配准确率

## 升级说明

- 覆盖安装即可（或在应用内点击「检查更新」自动更新），学习数据与题库不受影响
