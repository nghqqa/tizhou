# 题舟 v1.0.30

新增申论「单一题 / 综合题 / 公文题 / 作文题」四大题型分类、结构化卡片选题器与全站双主题视觉统一优化。

## 新特性与改进

- **申论四大题型分类与筛选**：自动将申论题归类为「单一题 / 综合题 / 公文题 / 作文题」（含书名/兜底题干的自动识别），申论作答页新增题型切换栏并支持与地区、关键词组合筛选
- **结构化卡片式题目选择器**：替换原生系统下拉框，悬浮列表按题型徽标、地区、年份、已评分数、题干摘要与教材来源分层展示
- **视觉统一性保障**：修复暗黑模式下徽标对比度并通过全站 19 页双主题双视口 UI 巡检零问题验证

## 升级说明

- 覆盖安装即可（或在应用内点击「检查更新」自动更新），学习数据与题库不受影响
