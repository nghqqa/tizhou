# 题库导入指南

本仓库**不分发任何题库数据**。应用是本地优先的空壳工作台,题库由使用者自行准备并导入,数据权利归各自来源方。以下三种导入渠道全部零 API 费用(模型功能为可选项)。

## 渠道一:工坊「直导题库」模式(推荐,扫描 PDF 也能吃)

适用:纸质题本/真题册的 PDF 或文本,含题本册 + 解析/答案册的成套资料。

1. 进入「知识构建」,原料目录选择包含题本与解析/答案的文件夹
2. 产物类型选 **直导题库(题本+解析/答案,零 API)**,勾选权利确认后开始
3. 扫描件自动走本地 OCR(首次使用先点「安装转换引擎」,含 OCR 组件约 200 MB,装在应用数据目录)
4. 题本与解析册自动分拣、按套号题号配对,直接发布入库

支持的答案版式:解析册【参考答案】标记块、书尾"1-5:BBDBC"分组答案页、独立答案文件。

## 渠道二:`tools/direct-import.mjs` 批量脚本

适用:大批量转换、需要跨库去重的场景。仓库内自带,用法:

```bash
# OpenExam sqlite 种子库 → 知识库 md(含题图 assets 拷贝)
node tools/direct-import.mjs build openexam <seed.db> <输出目录> <题图目录>

# OCR 后的题本+解析目录 → 知识库 md(套号题号配对)
node tools/direct-import.mjs build pianduan600 <OCR目录> <输出目录>

# 申论训练书 OCR 文本 → 作答题(材料+题干)
node tools/direct-import.mjs build shenlun-essay <OCR文件> <书名> <输出目录>

# 跨库去重(保留 primary 版本)
node tools/direct-import.mjs dedup <主库目录> <次库目录>
```

生成后在应用「环境与数据 → Markdown 知识库 → 连接目录」选中输出目录即可。带 `papers` 试卷归属记录的题库可直接使用「真题原卷模考」。

## 渠道三:自建 Markdown 题库

任何满足 frontmatter 约定的 md 目录都可以直接连接为知识库,字段详见「应用设置 → Markdown 格式提示」。

## 关于第三方题库数据

社区存在公开的题库项目(如 [OpenExam](https://github.com/lmk1010/OpenExam),sqlite 种子库格式可用渠道二脚本转换)。**此类数据多来自第三方网站的爬取整理,权利状态需使用者自行评估;本项目仅提供格式转换工具,不附带、不分发任何题目内容。**

## 注意

- 图片/表格扫描型资料分析题依赖材料图表,OCR 产物质量有限,建议优先使用自带图表资源的数据源
- 跨设备搬运已导入的题库:使用「应用设置 → 跨机迁移」
