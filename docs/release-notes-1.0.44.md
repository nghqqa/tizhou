# 题舟 v1.0.44

全面升级全站新中式书房 UI 与核心学习工作流体验，统一弹窗交互规范，并同步落地申论题库质量体检与入库门禁机制。

## 新特性与改进

- **知识中心与宽屏阅读体验重构**：补全主题令牌与深色模式对比度，知识中心与知识库工坊扩展为宽屏布局，支持体系手册置顶排序、分类胶囊筛选、820px 适读栏宽、阅读字号字体记忆、一键复制及上下篇切换；侧栏支持窄屏自适应折叠
- **申论作答、专项练习与模考全流程升级**：申论页面支持三列筛选、阅读排版控制栏、材料分标签页独立高亮与撤销删除，修复方格答题卡长文本下的输入法光标定位；专项练习支持答错后补标错因、相似题展开预览与错题筛选，模考新增吸顶状态条、主观题字数计数及 20 题分页复盘定位
- **全站统一弹窗规范与组件细节打磨**：清除全站 19 处原生弹窗，统一替换为 Fluent `<ConfirmDialog>`（高危清空需输入确认短语）与 Toast 提示；同步优化 AI 助教带题追问与变式对照、学习报告图表可读性、能力诊断整体进度、命令面板键盘滚动与地区选择器智能朝向，提升全部微型中文标签字号
- **申论题库质量门禁与解析修复**：新增申论残缺体检、联考跨卷拼补及入库质量门槛，修复显式知识文档被误切为题目的解析问题，并升级申论 AI 批改提示词
