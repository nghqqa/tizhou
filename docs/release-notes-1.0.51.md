# 题舟 v1.0.51

上线「备考规划 Agent」、五协议 Tool Calling、人工确认门禁与可编辑本机长期学习记忆，并集中修复 13 项协议兼容与状态稳定性问题。

## 新特性与改进

- **备考规划 Agent 与 11 项本机工具**：支持围绕个人学情、错题、模考、SRS 复习队列、笔记本与长期记忆开展多轮只读取数与行动规划，不瞎猜学习数据
- **五协议 Tool Calling 与 400/422 降级**：适配 OpenAI Chat、OpenAI Responses、Anthropic、Gemini 与 DeepSeek V4；网关不支持工具调用时自动平滑降级为纯问答
- **人工确认门禁（Human-in-the-Loop）**：发起训练/复习、追加题目笔记、补充错题标签均先以提案卡片呈现，用户点击「确认执行」后才落库
- **本机长期学习记忆抽屉**：备考目标、作息节奏与薄弱偏好持久保存在本地 SQLite，完全透明、可随时编辑或停用
- **13 项稳定性与协议修复**：涵盖笔记追加去重防覆盖、模式切换请求清洗、复习会话路由分流、多提案审批锁、超时诊断提示与 558 项单元测试保障

## 升级说明

- 覆盖安装即可（或在应用内点击「检查更新」自动更新），现有学习记录、错题本、笔记本与本地题库不受影响
