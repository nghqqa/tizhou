# 题舟 v1.0.28

补齐模考复盘闭环、AI 助教多会话持久化、题单导出打印、全局 `Ctrl+K` 快捷检索与资料分析分栏速查体验。

## 新特性与改进

- **模考复盘深度闭环 & 模块耗时分析**：真实累计每题作答耗时，复盘页展示各模块总耗时与均题耗时分布、顶部题号快速定位条、阅读自由放缩，支持就地收藏、标注错因、记笔记、带题问 AI 与一键「重刷本场错题」
- **AI 助教多会话持久化与带题追问**：对话记录自动落盘本地数据库，切页或重启不再丢失；支持从练习页、错题本、收藏夹、笔记库与模考复盘页一键带原题进入多轮追问
- **错题本 / 收藏夹 / 笔记库导出**：支持导出 Markdown 与可打印版 HTML，提供「导出含答案」开关（关闭即生成无答案二刷卷）
- **全局快捷检索（`Ctrl+K`）**：任意页面按 `Ctrl+K` 一键搜索并直达功能页面、知识文档正文或题库原题
- **资料分析分栏对照 & 速查卡**：材料题支持「左固材料、右切小题」分栏视图与同材料小题快切；内置可折叠百化分（`1/2–1/20`）与资料分析高频公式速查卡
- **细节与无障碍修复**：消除错题复习 0 到期时的多余报错条，保留已有错因标注不被后续空值覆盖，并修复模考交卷确认弹窗卸载后 `#root[aria-hidden]` 残留问题

## 升级说明

- 覆盖安装即可（或在应用内点击「检查更新」自动更新），学习数据与题库不受影响
