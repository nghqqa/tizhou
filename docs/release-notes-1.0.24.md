# 题舟 v1.0.24

针对 v1.0.19–v1.0.23 引入的新特性进行全面代码复核，集中修复 9 项稳定性与边界问题。

## 问题修复

- **申论评估与草稿保护**：评估进行中锁定切题入口并校验异步回调归属，杜绝跨题结果/草稿污染；切换「只看未做」、搜索过滤或离开页面前自动冲刷草稿，不再丢字
- **申论历史全文与排版细节**：历史作答新增「展开全文 / 收起全文」入口；修复评估结果区「综合反馈」与统计卡片 0px 贴边的问题
- **学习报告申论全量统计**：申论评估汇总改为按时间范围全量聚合，超过 100 条评估记录后平均分、最高分与累计次数依然准确
- **本地 OCR 边界强化**：收紧水印漂白阈值保护浅蓝/浅红彩色标题；页眉小图过滤增加视觉指纹同源校验与页数占比门槛，避免误删同槽位题干图；转换缓存策略键同步升级以自动刷新旧缓存
- **题库直导合订目录修复**：兼容合订总目录套数超过本册正文 2 倍的分册书，防止目录漏删导致套号错位

## 升级说明

- 覆盖安装即可（或在应用内点击「检查更新」自动更新），学习数据与题库不受影响
