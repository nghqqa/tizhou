# 题舟 v1.0.26

为专项练习、错题复习与模拟考试加入题目阅读区自由放缩与自定义字体支持。

## 新特性与改进

- **题目区自由放缩（85%–160%）**：无需修改全局缩放即可在答题页顶部通过滑块、`A- / A+` 或 `Ctrl + 滚轮` 随时微调题干、材料、选项、徽标与解析字号，点击百分比一键复位 `100%`
- **字体预设与自定义本机字体**：内置默认黑体、书卷宋体、公文仿宋、舒朗楷体，并支持直接填写本机已安装字体名称（如 `霞鹜文楷`、`思源宋体 CN` 等），设置自动持久化并在练习、复习、模考间同步

## 升级说明

- 覆盖安装即可（或在应用内点击「检查更新」自动更新），学习数据与题库不受影响
