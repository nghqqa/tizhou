# 题舟 v1.0.17

针对真实用户反馈「知识库工坊转换环境安装不上」，一次根治四类根因：转换环境从此零门槛，没有 Python 也能一键装好；开启系统代理、杀软拦截、Python 没进 PATH 等常见故障全部有自动兜底。

## 零门槛自动部署独立 Python 3.12

- 优先复用本机 Python 3.10+：除 PATH 外扩展扫描 Windows 常见固定安装位置（全局 py 启动器、per-user 与全机器版本化安装目录、uv 管理的解释器），装完 Python 免重启应用即可识别
- 自动过滤微软商店的假快捷桩（点了只会跳商店页的 python.exe），并校验候选解释器的 venv 模块可用
- 本机没有 Python 时自动下载独立便携版 Python 3.12（约 21 MB）到应用数据目录：npmmirror 主源 + GitHub 备源双源自动回退，字节数与 SHA-256 双重硬校验，Windows 系统自带 tar 解压；不写注册表、不改系统环境

## 镜像探活修复与多源自动故障切换

- 修复开启系统代理时清华源返回 `403` 被误判「可达」的问题：探活改为访问真实包索引页，只有 2xx/3xx 判可达
- `auto` 模式下 pip 安装遇失败自动切换备用镜像源重试（可达国内源按测速排序，探活未过的源留作兜底），首个成功的源提升为后续组件的首选源
- 手动钉死镜像源遇 `403` 或空版本列表时，直接给出可操作的排障提示（建议改回「自动」或「腾讯云镜像」）
- 补齐 GPU 加速回退重装 CPU 后端时漏传的镜像源参数

## 半残虚拟环境自愈

- 首次建环境被杀毒软件拦截或中断，留下「有 python.exe 没有 pip」的残缺环境时，重试会自动执行 `ensurepip` 补装或清理重建，不再永久卡死 `No module named pip`
- 便携运行时下载带超时中断：主源半途挂起自动切备源，不再永久占用安装状态
- Windows 解压固定优先使用系统自带 `System32\tar.exe`，不再被 PATH 里靠前的 GNU tar 误伤（`Cannot connect to C:`）

## 界面细节

- 下拉框长文本省略号样式精确作用到内层原生 select，申论等页面长题干不再溢出

## 测试

- 394 → 432 项单元测试：新增镜像探活判定矩阵、候选源队列排序与换源重试、Python 深度发现与商店假桩过滤、便携运行时完整性校验与篡改拦截、半残 venv 自愈、System32 tar 解析等离线确定性用例；24 项真实 Electron E2E 保持覆盖

## 升级说明

- 覆盖安装即可，无需卸载旧版本；已装好的转换环境不受影响，无需重装
- 若此前因「未找到 Python」或 `No module named pip` 安装失败，升级后直接重新点击「安装转换引擎」即可
