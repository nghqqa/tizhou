# 题舟 v1.0.47

聚焦行测考场节奏与申论全流程闭环，正式上线十一项公考备考核心功能，并优化模拟考试页排版结构与全局表单按钮防溢出细节。

## 新特性与改进

- **行测模考配比预设、分组答题卡与模块配速**：新增资料/言语/判断/数量高频冲刺预设与国考地市 130 题/省考联考 120 题仿真配比组卷（资料分析继续严格锁死 5 题连续不拆散）；考场接入左侧吸顶材料分栏、可调顺序的五大模块分组答题卡及实时模块配速预警；上线「真题套卷进度墙」一览历年套卷完成轮次与最高分
- **五阶艾宾浩斯间隔复习与蒙题转错题**：新增 `1→3→7→15→30` 天阶梯间隔调度与看解析后 `1–4`（重来/困难/掌握/秒杀）记忆评级，错≥2 次顽固错题连对门槛升至 3 次并支持错题库独立筛选；支持将专项练习、结算页与模考复盘中的「蒙对/不确定题」一键批量转入待复习队列
- **效率四象限矩阵与计划自动联动**：学习报告页新增「正确率 × 均题耗时」四象限效率矩阵图表，点击气泡直达薄弱模块补强；日常刷题、错题复习、AI 变式训练与知识阅读打卡自动推进活跃学习计划进度并自动结项
- **申论整卷模考、修订 Diff 与备考随身工具**：新增 150/180 分钟申论整卷连作模考（交卷保存草稿不污染客观错题本）、一稿 vs 二稿行内文本 Diff 对比、无 AI 采分点自查清单与内置 16 组规范词的随身金句抽屉（支持知识中心划词收藏）；同步带来资料分析 2 分钟速算热身与知识中心/规律中心主动回忆闪卡
- **界面布局打磨**：优化模拟考试页「新建模考」半行留白、按钮间距与 3×2 预设卡片对称排版，修复长试卷名撑破卡片及申论草稿加载竞态等问题
