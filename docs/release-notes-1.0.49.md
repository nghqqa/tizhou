# 题舟 v1.0.49

围绕考场实战配速、科学估分与考前纸质二刷，带来四项核心提分能力与侧栏文字显示修复。

## 新特性与改进

- **随手草稿纸进阶（缩放、多页与换题清屏）**：支持拖拽右下角自由调整尺寸、新建最多 5 页独立草稿签，以及开启「换题清屏」（同材料资料分析 5 连题自动保留草稿，支持 `Ctrl+Z` 撤销防误清）
- **行测目标分拆解与分模块加权估分**：学习报告页支持按国考地市/副省/省考联考分值权重测算当前预估分、各模块距目标差题数与最高性价比突破方向
- **模考超时黑洞榜与考前 5 分钟涂卡提醒**：复盘页新增沉没成本 Top 10 榜单并支持一键收入复习；行测考场最后 5 分钟自动提醒填补未答与待查题
- **错题本 / 收藏夹 / 笔记库 A4 试卷级 PDF 导出**：零依赖直接生成 A4 打印级 PDF，支持「无答案/答案附后试卷版」与「题解对照版」，自动内嵌本地题图与页码
- **侧栏底部体验修复**：恢复左侧栏底部「深色模式 / 检查更新」完整文案与窄栏防挤压排版

## 升级说明

- 覆盖安装即可（或在应用内点击「检查更新」自动更新），现有学习记录、错题本、笔记本与本地题库不受影响
