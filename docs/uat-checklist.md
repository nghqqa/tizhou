## UAT-13 GPU 加速组件（可选安装）

| 项目       | 方式   | 状态 | 备注                                                                          |
| ---------- | ------ | ---- | ----------------------------------------------------------------------------- |
| 1 独显检测 | manual | ⬜   | 有独显机器显示「启用 GPU 加速」按钮与适配器名；无独显机器不显示入口           |
| 2 安装探针 | manual | ⬜   | 启用后进度条走完显示「GPU 加速已启用」，状态行变为已启用 DirectML             |
| 3 转换提速 | manual | ⬜   | 启用后导入扫描 PDF，文件消息显示「GPU 加速」，速度较 CPU 提升                 |
| 4 回退保护 | manual | ⬜   | 移除 GPU 加速后 OCR 仍正常（CPU 后端恢复）；人为制造 DML 失败时自动回退并提示 |
