# 题舟 v1.0.22

完善申论连刷与复盘闭环：新增申论上一题/下一题导航、单题历次评估回看，并在学习报告中加入申论作答记录汇总。

## 申论与复盘增强

- **上一题 / 下一题与只看未做**：申论作答页支持一键切换上一题/下一题（自动保存草稿）、显示 `第 N / M 题` 进度，可按「只看未做」过滤并在下拉列表查看每题最新评估分数
- **单题历史记录与二稿精进**：切回已做题目自动回显最近一次评估结果；右侧「历史记录」标签页支持回看历次作答与对应点评，并一键「载入修改」继续打磨二稿
- **学习报告申论作答记录**：学习报告新增「申论作答记录」区块，按时间范围统计累计评估次数、覆盖题数、平均分与最高分，点击「查看复盘」可直达原题与历史点评

## 升级说明

- 覆盖安装即可（或在应用内点击「检查更新」自动更新），学习数据与题库不受影响
